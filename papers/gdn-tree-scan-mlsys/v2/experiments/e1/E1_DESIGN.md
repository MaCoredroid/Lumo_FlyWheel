## Binding rule (mandatory; corrected per the parent's E1 design preflight)
Two keys, never conflated: `physical_step_id` (one engine forward = one physical step, shared by every request scheduled in it) and `(request_id, step_idx)` (per-request rows). Wall intervals belong to PHYSICAL steps and are summed ONCE over unique physical steps; committed tokens are summed over per-request rows joined to those physical steps. Aggregate throughput = Σ committed tokens (all requests, joined rows) / Σ wall over UNIQUE physical steps — e.g. 4 concurrent requests committing 5 tokens each in one 0.24 s physical step = 20 tokens / 0.24 s = 83.3 tok/s, NOT 20 / (4 × 0.24). Per-request latency uses that request's own physical-step intervals. Every reported E1 number is computed only over events that carry the same IDs in all three streams:
1. **Committed output**: per request, per decode step: `(physical_step_id, request_id, step_idx)` → committed token ids (accepted + bonus), num_drafts, num_accepted — emitted by ONE server-side recorder at the committer (the same site the E7b commit hook uses), and cross-checked against the API-side `token_id:` logprob stream (existence of a consistent path per step, as the provenance inspector does).
2. **Wall intervals**: per `physical_step_id`: monotonic timestamps at forward start/end of the engine step (start-to-start deltas between consecutive pure-decode physical steps define the step wall), recorded once by the same recorder; a physical step that contains any prefill/chunk is flagged and excluded from pure-decode wall (its tokens are excluded too).
3. **Component spans** (only if reported): kernel/committer/drafter CUDA-event spans keyed by the SAME `physical_step_id` (and request row where the span is per request); a span without an ID is dropped, never attributed.
Aggregates: tokens-per-wall-second = Σ committed tokens over joined rows / Σ wall over the UNIQUE physical steps those rows belong to; accept-per-event = Σ accepted / (number of per-request rows); no counter-derived global ratios; no residual "host time" = wall − (sum of differently scoped spans). If a component is not measured on the same support, report it as unmeasured.
