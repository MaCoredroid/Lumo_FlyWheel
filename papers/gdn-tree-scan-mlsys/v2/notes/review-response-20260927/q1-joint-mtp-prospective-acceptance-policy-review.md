# Joint target/MTP continuation: minimum prospective acceptance contract

2026-09-29. **Source-grounded proposal only; not an approved policy, gate, launch or result.** No candidate joint-MTP outcomes have been used. No implementation, paper, policy, gate or scientific criterion was changed; no GPU/model action occurred.

**Verdict:** the existing rules fix structural/publication exactness, the GDN component numerical envelope, and a target-only exact O2 greedy decision gate. They do not supply a numerical acceptance tolerance for newly computed full-model MTP KV or scores. Earlier MTP readiness reviews prescribe exact categorical comparisons, but the executable case/phase/operator/repeat acceptance contract still needs a prospective freeze. The smallest defensible extension is an explicitly named **finite-corpus MTP categorical-continuation gate**, conjoined with the existing structural and state-component checks. It must not silently become “full MTP numerical equivalence” or “full Q1 passed.”

## Smallest missing prospective contract

Freeze this as a separate versioned supplement **before candidate MTP outcomes**, with the source/job/observation manifest and reducer bound to the exact files. It formalizes the categorical requirement in `N/q1-native-mtp-adapter-source-readiness.md:64–70`; it does not loosen any existing requirement.

1. **Population and eligibility.** Keep the 84 predetermined cycle-0 path/prefix cases, processes A/B and two repeats (336 observations per tested route), fixed model/precision/serving settings and aligned/nonpacked native reference. Keep packed controls separately diagnostic and preserve the original adverse natural-prefill results. Three prospectively selected joint prefix/root sources are an input inventory, not a three-case qualification denominator (`C/tools/q1_joint_source_plan_v1.py:18–25`). Native A/B/R2 must use the same authenticated joint source and include MTP allocation/history. Require complete native evidence, exact joint logical O0, finite raw payloads and stable categorical reference outputs at every declared checkpoint; an unstable native winner or ordered top-k stays baseline-unqualified, not excluded or replaced. Record within/across-process state/logit equality separately. Do not silently strengthen the already frozen target baseline rule from stable greedy to byte-identical logits: `q1_native_corpus_v1.py:240–257` distinguishes those quantities.

2. **Exact observation keys.** Bind `(case, process, repeat, phase, logical extent, request/generation, selected logical token, input token/position, actual hidden-source row, operator/k/dtype)`. The minimum declared connection distinguishes (a) selected MTP first pass at target extent P+1+L, with z already used as its shifted input; (b) its genuine next MTP followup using that pass's actual returned hidden and chosen draft; and (c) the MTP first pass after actual target z, whose next-token input is the actual target O2 decision. Target O2 itself is a fourth, separate observation. Use real production outputs, not extra surrogate forwards. Export full logical materialized MTP KV at the already specified boundaries, not just the remap witness's bounded suffix. These distinctions follow `N/q1-joint-target-mtp-common-o0-design-review.md:35–41`.

3. **Categorical predicate, zero allowed disagreements.** At each declared matched checkpoint require the candidate's actual raw **spine argmax ID** and actual **ordered production candidate IDs** to equal the native executable results. Current Hydra selection is `argmax` plus ordered `torch.topk(logits,3)` on the same full-vocabulary row (`.../cpu-lumotree-source-20260929T012000Z/result/sources/v1/spec_decode/eagle.py:3158–3165`). Bind the actual consumed k for every declared phase; k=2 or k=32 records cannot substitute for k=3, and `topk(k=32)[:3]` is not its tie-order oracle. Do not substitute top-k's first ID for argmax, replace native top-k ordering with stable argsort, accept set-only equality when rank drives physical candidates, or exempt small margins. Preserve exact ties, set/rank differences and continuous score margins. Stable exact ties may pass the pinned operator's categorical test; unstable native ordering cannot. The existing same-input adapter check remains conjunctive.

4. **Do not conceal divergence.** Save natural outputs before diagnostic forcing. If the first draft decision differs, record that gate failure and label the later self-fed MTP inputs unmatched; do not force the native draft into the candidate and present the later scores as natural agreement. Likewise after-z MTP must use each arm's actual target O2 decision, not the server's terminal stop token. Keep target fixtures/forced path/z identical for the target-continuation comparison as already declared; forcing does not turn different natural proposals into agreement.

5. **Independent structural prerequisites stay mandatory.** Authenticate the full joint source/raw prefix lineage; perform one fail-stop pointer-stable union import; bind the actual post-import target+MTP snapshots; retain destination bootstrap separately. Require exact candidate-owned remap/copy and untouched-region witnesses, correct selected hidden/token/position handoff, actual deferred seal, and next consumer. Any missing/wrong-source/partial-import/nonfinite/identity failure invalidates that observation and prevents aggregate pass. Wrong-state negatives must still trigger structural/state detection even if categorical IDs agree. Existing CPU controls can be reused; this note proposes no extra workload or inference cell.

**Aggregate label:** only if every predetermined required observation is eligible and all stated predicates pass, report “joint-source, finite-corpus target and MTP categorical continuation with exact publication/ownership checks” for the explicitly captured phases. A first-pass plus one-followup observation does not establish all later proposal levels, all future cycles, or a free-running trajectory. The executable supplement must spell out its phase coverage rather than call root-only agreement the whole next-draft tree.

## What remains unspecified, and honest narrowing

No reviewed contract supplies an independently justified C2/error budget for newly computed MTP K/V, MTP hidden states, or MTP full-vocabulary scores across different target histories/dispatch shapes. A deterministic native repeat envelope is zero observed variability, not permission for an arbitrary nonzero candidate tolerance. Neither the native packed/unpacked gap nor the GDN paired envelope can become that allowance (`N/q1-fullmodel-reference-design-review.md:99–106`). Preserve raw per-surface errors and exact-byte equality diagnostics for all passes and failures.

An explicit prospective **zero-byte-difference** criterion would be a defensible strict equality claim if the parent chooses that distinct scope, but it is not an already frozen requirement and need not be invented merely to report the categorical gate. A bounded nonzero MTP numerical-equivalence claim requires a separately justified, reviewed criterion; current sources do not provide one. Until then, label MTP numerical equivalence **unqualified**, even if all categorical/publication checks pass. Do not mark full Q1 complete, silently remove its open requirements, or authorize stages whose own prerequisites require full Q1. Continuous cycles without rehydration, APC/lifecycle and any existing held-out requirements remain separate; this 84-case connection neither expands nor closes them.
