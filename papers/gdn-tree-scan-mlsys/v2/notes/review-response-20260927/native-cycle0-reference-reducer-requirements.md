## Required checks, in execution order

1. **Bound source, runs and coverage before comparing numbers.** Require the exact fixture file and recomputed canonical identity, all 84 unique calibration case IDs and their unmodified prefix/path/chain fields, cycle zero, exact arm/process/repeat values, and the declared request order. Require exactly one seal and matching successful driver receipt per expected observation, with no duplicates, substituted cases, missing observations, unexpected cases or invalid-control sidecars. Reject an empty or partial corpus; retain every failed/missing case in its denominator. Recompute expected request counts instead of trusting `job.expected_requests` or directory length. The builder at `tools/q1_reference_job.py:33–54` supports this population but does not reject repeated case IDs or constrain non-smoke process names/repeats by itself.

2. **Authenticate actual execution identity.** Each process needs its own approved launch/job/config/command binding, boot receipt, runtime hooks/runner patch receipt, immutable image and model/tokenizer/loader bindings. Bind the pinned patched FA2 binary and interface/backend/layer sources and actual `FlashAttentionImpl` version 2 on all 16 layers; require spec-off, B1, aligned cache mode, FP32 recurrent state, BF16 conv/KV and the declared APC/scheduler settings. All 48 layers must explicitly attest the correct packed attribute for that arm. Hooks implement these observations at `q1_reference_hooks_v2_1.py:249–345`; `fatal=false` alone is not a complete identity check. A/B labels alone are insufficient: require distinct owned container/engine lifetimes and process boot receipts, no restart, and completed cleanup between sequential boots. PID equality across containers is permitted; PID alone does not establish process independence. Compare scientific settings across A/B, and keep only the declared packed-route difference across arms.

3. **Authenticate each case and its expected sequence.** Recompute its canonical `record_sha256` and require `valid is True`, empty problems, inactive-at-seal, exact job/run/arm/process/repeat/case/observation identity, and the expected distinct request association. Bind the control's prefix length/hash to the frozen prefix, rather than merely checking that control and record agree. Require API prompt-token parity. Read the recorded consumed execution trace and require exactly `r + accepted drafts + z`, in that order, at the frozen positions and computed-token counts; `len(chain)=L+2`, `O0.materialized_tokens=|P|`, `O1.materialized_tokens=|P|+1+L`, and `O2.num_computed_before=|P|+1+L`. The last O2 is the forward **consuming z**, predicting the token after z. Require the single terminal forcing event and expected count `len(chain)+1`, with completed request receipts; natural-sampler values remain separately labeled observations. See hooks `:478–514, 521–573, 578–604` and driver `:89–123`.

4. **Validate complete logical state, not just a claimed digest.** For both O0 and O1, require the exact frozen 48 GDN names and 16 attention names among 64 model layers, not merely those counts. For this pinned model the observed native names are `language_model.model.layers.<i>.linear_attn` for `i % 4 != 3` and `language_model.model.layers.<i>.self_attn.attn` for `i % 4 == 3`. Require conv BF16 `[3,10240]` and SSM FP32 `[48,128,128]`, positive allocated state rows and the declared group mapping. Recompute per-layer/aggregate digests from authenticated contents in the hooks' sorted-name order. Compare logical contents across repeats, never physical row IDs, addresses, timestamps or block IDs: these legitimately changed in the accepted smoke.

   For attention, require the independently declared group/geometry, BF16, K/V axis 2, four KV heads and head dimension 256. The observed native logical kernel block size is **64**, although configured allocation block size is 1024; validate against the bound runtime kernel-block mapping rather than substituting 1024. Require exactly `extent // kernel_block_size` complete blocks and the exact valid tail, consecutive logical indices, positive unique in-range physical blocks for each layer and correct tail absence at exact multiples. Recompute all K/V logical digests. Raw lengths follow the declared geometry; parse every referenced BF16/FP32 payload for finite values, and require actual hash and length. Ignore unmaterialized tail slots rather than treating them as valid history. Exact layer/geometry coverage must be checked before using generic object-authentication helpers (`hooks :89–152, 386–473`).

5. **Recompute raw next-forward decisions.** Require a full 248,320-entry little-endian FP32 archive (993,280 bytes), the frozen source logit dtype, exact content SHA, and all finite values. Recompute smallest-ID maximum, top1, top2 excluding just the chosen index, margin and exact tie count, and compare every saved summary. The hooks convert the BF16 logits losslessly to FP32 before archiving. The patcher places this capture directly after `compute_logits` and before grammar/sampling (`q1_patch_reference_runner_v2_1.py:30–44`); its exact patched-source binding matters. A finite digest or matching saved argmax field is not a substitute for parsing the raw vector. Stable exact ties are allowed under the frozen tie rule and must be counted with zero margin; a changed winner fails baseline decision stability regardless of small margin.

6. **Reduce per case, separately per arm.** For each `(arm, case_id, cycle=0)`, compare A0/A1 and B0/B1 within process, then all four across processes. Output separate exact O0/O1 per-layer/surface and raw-O2 byte equality, plus recomputed winner stability. Require an exact common logical O0 for the intended same-input native-repeat claim. If O0 differs, retain an APC/prefill finding and mark the shared-O0 comparison unqualified; current native hooks do not restore one canonical O0 between repeats. An explicit native importer/replay design would be necessary to repair that premise, not an error tolerance. If deduplicating one O0 per prefix across different paths, first prove all of those O0s equal; otherwise keep case-specific snapshots.

   The adopted decision contract requires deterministic **winners**, not a new arbitrary full-model allclose tolerance. Therefore keep `state_bitwise_repeatable`, `logits_bitwise_repeatable` and `decision_stable` distinct. If O0 is exact and O1/logit bytes differ but winners remain stable, disclose the observed numerical variability; do not claim bitwise repeatability and do not automatically convert that variation into a candidate allowance. If any primary winner varies, mark that case `UNCOVERED`/baseline-unqualified and keep it in the 84-case denominator. Missing, invalid, nonfinite or baseline-unqualified **primary** observations prevent an all-cases primary reference verdict. Missing packed observations make the two-arm corpus incomplete, without rewriting an independently valid primary result. Packed-control winners and error magnitudes never replace the aligned reference or enlarge its criterion. Report aligned-versus-packed results as a separate table.

## Existing code and evidence worth reusing

- `tools/q1_reference_driver_v2.py:40–74` and hooks `expected_object_lengths`, `authenticate_objects`, `reconstruct_logical_kv` provide reusable sealing/byte-authentication and logical-KV reading. The driver's import is still `q1_reference_hooks_v2`, whereas runtime uses v2.1; an AST comparison in this review confirms those three helper functions are identical in both. They are **not** a complete coverage/state/numerical reducer: absent surfaces can produce no expected objects, recorded geometry drives lengths, and finite checks are not independently repeated by these helpers.
- **Do not reuse the driver's global repeat booleans as verdicts.** `q1_reference_driver_v2.py:130–131` compares all receipts together. Different prefixes/paths can correctly produce different states and winners. Replace those meanings in the corpus reducer with per-case groups; driver `complete` means collection completeness only.
- `notes/review-response-20260927/audit_recovered_smoke.py:47–151` is a useful independent NumPy-only reader template. It checks exact layer sets, logical ordering, raw finite values, raw argmax and state digests. It is hardcoded to one smoke case and uses Python assertions, so it needs generalized frozen-domain handling and explicit validation failures (or an explicit optimization refusal) before becoming the corpus reducer. Preserve its independent reduction rather than calling the producer's summaries.
- `tools/q1_candidate_stage1_reduce.py` is a one-case diagnostic reducer, **not** a native-corpus reducer. It selects the first `r0` native record at lines 36–38 and trusts recorded/job argmax at line 47; these semantics cannot be generalized by merely pointing it at 84 cases.
- The accepted native smoke `runs/q1-native-smoke/q1-native-smoke-recovered-20260928T031726Z` already supplies **one root-only calibration case, aligned arm, process A, two valid repeats**. This pass reread its small records/source bindings and snapshotted them; it did not repeat the 1.2-GB payload audit. ## Small meaningful CPU controls before the collection gate

Use a complete synthetic metadata domain plus small raw-vector fixtures, and the real two-record smoke as a bounded integration fixture. Require refusal for a missing/duplicated case, A renamed to B without a fresh launch, swapped arm/job/source binding, empty layer dictionaries, wrong layer replacing one of the required 48/16, truncated or nonfinite raw object, wrong logical-block order/tail length, z not consumed, same saved argmax but altered raw winner, and a missing packed record masquerading as a complete two-arm corpus. Positive controls should allow different physical cache IDs with equal logical content, different winners in **different cases**, shared content-addressed objects, and a stable exact tie. A finite same-case perturbation with unchanged winner should report non-bitwise variability while preserving the narrower decision result; a perturbed winner must remain baseline-unqualified. No new GPU work is needed for these controls.

The smallest useful next output is an immutable per-case eligibility table plus its authenticated O0/O1/O2 reference index and exact coverage/missing table. It qualifies the declared native reference corpus only. Candidate state/publication, MTP, multiple cycles, lifecycle and held-out qualification remain separate gates.
