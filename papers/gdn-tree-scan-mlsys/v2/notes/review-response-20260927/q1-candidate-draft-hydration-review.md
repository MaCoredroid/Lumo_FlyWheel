## Concrete repairs to incorporate

**1. Validate all destinations together and reread after the entire import.** `apply_plan:110–117` hashes a destination immediately after its copy; `logical_digest_after_import:126–136` hashes those saved receipts, not the final live tensors. A later layer can overwrite an earlier imported region while both receipts remain successful. This is relevant to the real layout: `fr10_gdn_tree_kernel.py:7909–7945` requires **16 exact conv-bank alias groups of width three**, spanning the three SSI groups, with matching SSM alias groups. The current committer explicitly reports `alias_row_unique` at lines 9237–9241. Blanket rejection of shared bank storage would therefore also be wrong.

Plan all 48+16 layer destinations before copying. Preserve the allowed alias topology and require selected destination byte regions to be disjoint where their logical contents differ, including distinct running rows inside a shared bank. Reuse the production lease/alias constraints where possible. After all copies, reread **every** imported region, then compute the native digest in exactly the reference's sorted layer order and K/V logical-block order. Require the expected complete layer sets, no duplicates, exact object shapes/dtypes/lengths, per-region equality, and equality to the bound native O0 digest. A hash of partial or stale receipts is not an O0 seal.

**2. Make the guard and identity claims accurate.** The planner provides only convolution padding (`plan_gdn_layer:63`) and unmaterialized KV-tail (`plan_attention_layer:86`) guards. No untouched SSM/conv rows or other KV blocks are guarded by `apply_plan`. Tests at lines 48–54 and 73–80 independently compare some untouched regions in ordinary contiguous fixtures; that does not implement runtime detection. Check the production strides/row spans and the global permitted-write region, and enforce the claimed complementary-region guards, accounting for legitimate writes by other alias-group layers. The existing inner conv-stride check alone does not exclude overlapping rows. If a guard is intentionally omitted, the runtime receipt and docstring must not claim it ran.

`identity:46` covers pointer, shape, strides, offset, dtype and device. It does not bind the actual layer tensor objects, their shared base-storage relationship, or the existing bank tuples used by captured graphs. Preserve and compare those bindings across the complete import using the accepted R-SNAP/production lease contract; checking the same local dictionary's tensors before and after `copy_` does not attest that the runner registry still points to them.

**3. Define the failure boundary before mutation.** Object authentication occurs one item at a time (`apply_plan:110–114`). A missing SSM object raises after its convolution has already been imported; the existing `object_missing` test deletes precisely that second object but only asserts an exception. Prevalidate every source object and destination plan before the first copy. A later device/readback failure can still leave partial state: either restore verified shadows or mark the entire import/process unusable and prevent any subsequent forward or repeat on it. A generic INVALID case label alone does not undo writes. This does not require implementing rollback if a hard abort is the chosen contract.
