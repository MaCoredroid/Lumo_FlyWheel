## Reproduction and outputs

Run the configured Python interpreter on `scripts/recover_git_history.py`. It reads immutable Git blobs, rejects unresolved LFS pointers, verifies evaluator/runner/summary identities, reduces task counts and durations, checks the bounded historical component records, and writes:

- `results/history-recovery-20260930/audit.json`: 123 input Git bindings (commit, path, blob, byte count, SHA-256), all 48 attempt records, four calibration projections and the qualification-era register.
- `july22-attempts.csv` and `july22-table.tex`: task-level and paper projections.
- `raw/`: unmodified saved task/evaluator records and bounded qualification records; synthetic records are explicitly labelled safe projections.
- `history.tex`: the paper appendix, linked from the existing comparator discussion.

The raw recovery bundle is separate from the LaTeX source dependency package. The former supports history inspection; the latter reproduces the manuscript build. No new GPU boot, workload attempt, timed mechanism cell, or unit test was run. Q1/WP remain closed and WC remains superseded. The scheduled monitor remains deleted.
