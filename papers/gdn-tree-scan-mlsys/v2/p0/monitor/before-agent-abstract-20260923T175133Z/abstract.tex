\begin{abstract}
Tree speculative decoding for recurrent-hybrid language models must preserve ancestral state during verification and publish a valid selected continuation. We present GDN Tree-Scan, a Gated DeltaNet verifier organized around a shared tree descriptor, branch-local computation, device probability arithmetic, and publication across recurrent, convolution, and attention state. Its GPU execution uses temporary branch states and accepted-path replay through a shared node-update body. We explain memory--recomputation tradeoffs and optimizations for draft-logit reuse, convolution, operand preparation, and attention execution. Our application target is long-running coding agents. A dated deployment case uses Qwen3.8-27B NVFP4 on GB10 with ten selected SWE-bench Verified Astropy tasks: six resolve and four fail their tests, with recorded agent times from 1.67 to 41.24 minutes. Across 265 request-level time-per-output-token observations, the inverse mean is 28.20 tokens/s; this serving statistic is distinct from task-completion speed. The cohort is a completed segment of a resumed development campaign, not a representative benchmark sample or a matched native comparison. Separate same-input arithmetic and bounded continuation checks characterize the implementation; neither local compact-state candidate passes all frozen promotion criteria. No local-document throughput result is used as agent-performance evidence. A matched native-versus-tree task study remains necessary to establish an application speedup.
\end{abstract}
