\begin{abstract}
Tree speculative decoding for long-running coding agents must preserve coherent continuation across repeated generation and tool calls. We present LumoTree, a tree-verification implementation for Gated DeltaNet hybrid models. It executes recurrent paths in parallel, reuses state tiles within each path, and uses a shared logical tree to coordinate native recurrent replay, convolution-history gathering, and attention-cache remapping. The implementation combines fused candidate selection, GPU-resident acceptance, and grouped split-K attention. Component tests establish candidate-selection parity and recurrent agreement within the declared paired error bounds. Full-model qualification remains unestablished: a native-reference experiment preserves greedy decisions on all 84 tested paths but reproduces the ordered top-three MTP choices at all declared phases on only 68 across independent processes, preventing candidate admission under the frozen rule. Exploratory Qwen3.8-27B NVFP4 runs on GB10 attain 27.27--29.09 pooled tokens/s across three tree revisions, versus 26.89 for SGLang EAGLE, on two shared SWE-bench Verified Astropy tasks with nonempty patches. These retrospectively selected deployments do not establish a current same-stack advantage or general quality preservation.
\end{abstract}
