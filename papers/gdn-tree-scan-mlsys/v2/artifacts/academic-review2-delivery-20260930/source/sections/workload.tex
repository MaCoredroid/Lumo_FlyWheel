We deploy \sys{} with Qwen Code on ten Astropy tasks from SWE-bench Verified. The agent inspects repositories, edits files, executes tools, and produces a patch for each task. Model serving runs on a single GB10. Six patches resolve their tasks and four fail tests; agent durations range from approximately 2 to 41 minutes. Appendix~\ref{app:workload} gives the task-level outcomes.

For completed request $r$, let $n_r$ be the output-token count, $\ell_r$ the server-recorded end-to-end latency, and $f_r$ the time to first output. We report the pooled decode rate
\begin{equation}
 D_{\mathrm{pool}} =
 \frac{\sum_{r=1}^{R}(n_r-1)}{\sum_{r=1}^{R}(\ell_r-f_r)}.
 \label{eq:pooled-decode}
\end{equation}
Counts and durations cover the same completed requests, including internal compaction requests. The numerator counts output intervals, and the denominator excludes first-output latency and between-request agent/tool work. Overlapping requests contribute their durations separately. Thus, $D_{\mathrm{pool}}$ measures token production over accumulated request durations rather than aggregate wall-clock throughput.

The ten-task deployment attains \textbf{25.63 pooled tokens/s} over 265 completed requests. On two additional Astropy tasks (12907 and 13033), three earlier \sys{} revisions recorded 27.27--29.09 pooled tokens/s, while two SGLang EAGLE runs recorded 26.89 and 30.70 tokens/s.\footnote{The two-task comparison was selected retrospectively from completed SGLang records. All three \sys{} revisions and the 26.89 tokens/s SGLang run resolved task 12907 and produced a test-failing patch for task 13033. The 30.70 tokens/s SGLang run resolved task 12907 but produced an empty patch for task 13033 after a thinking-only response reached its 32,768-token cap; that task did not reach test evaluation. Restricting the comparison to normally completed, nonempty-patch attempts excludes this run.} These deployments use different serving configurations (Appendix~\ref{app:settings}); comparison limits are discussed in Section~\ref{sec:limitations}.
