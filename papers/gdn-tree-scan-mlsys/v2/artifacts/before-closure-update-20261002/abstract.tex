\begin{abstract}
Tree speculative decoding for hybrid language models must preserve one coherent continuation across recurrent, convolution, and attention state. We present LumoTree, a verifier that executes recurrent paths in parallel, reuses state tiles within each path, and coordinates native recurrent replay, convolution-history gathering, and attention-cache remapping through a shared logical tree. Fused candidate selection, GPU-resident acceptance, and grouped split-K attention support the verification cycle. Component experiments characterize exact candidate selection and bounded recurrent error. On a single NVIDIA DGX Spark (GB10), sampled replay with Qwen3.8-27B NVFP4 records 28.79 pooled tokens/s for LumoTree versus 26.12 for five-token native multi-token prediction on the same vLLM stack. A disjoint 43-request corpus records 30.67 versus 27.41 tokens/s in one run per arm. A separate 30-attempt coding-agent study on ten SWE-bench Verified tasks does not reproduce this decode-rate ranking. Full-model comparison covers 147 forced continuation cycles, but insensitive fault controls leave its preregistered verdict inconclusive. The results support a scoped replay-rate advantage, rather than established full-model equivalence or task-completion speedup.
\end{abstract}
